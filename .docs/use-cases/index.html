Como distribuir as atividades

Distribua os UCs entre os alunos. Cada aluno trabalha em seu fork e envia uma branch ucXX para a base central saas-evolution/fase01. Os pré-requisitos incluem código e endpoints usados pela interface e pelos testes. A numeração identifica a atividade; ela não determina a ordem de implementação.

Só inicie uma atividade quando todos os seus pré-requisitos estiverem integrados na base central pelo professor. O comando bun .docs/use-cases/preparar.ts ucXX verifica isso antes de criar a branch.

Os arquivos de preparação compartilhada são idênticos em todos os tutoriais e podem entrar pelo primeiro PR de qualquer frente. Cada UC acrescenta seu próprio ponto de composição, página e testes.

Ondas possíveis de integração

Validação e referência do professor

O código de cada arquivo é reproduzido integralmente nos HTMLs. Os pacotes JSON contêm os mesmos conteúdos e hashes para reproduzir cada atividade a partir da base original e testar o grafo de pré-requisitos.

A branch saas-evolution/fase01-teste contém a implementação completa. Ela é uma referência de execução; os alunos criam suas branches a partir de saas-evolution/fase01.
